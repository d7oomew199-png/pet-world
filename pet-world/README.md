# Pet World
موقع متجر إلكتروني عربي للحيوانات الأليفة، مستوحى من صورة التصميم التي زودني بها المستخدم.

## الصفحات
- `index.html` الصفحة الرئيسية.
- `animals.html` الحيوانات الأليفة.
- `services.html` الخدمات والمستلزمات.
- `contact.html` التواصل.

## التشغيل
افتح `index.html` في المتصفح. جميع الصور المستخدمة موجودة داخل `assets/images`.
ملاحظة: نموذج التواصل تجريبي ولا يرسل الرسائل فعلياً قبل ربطه بخدمة خلفية.


الصفحات المنفصلة المضافة: food.html للطعام والتغذية، care.html للعناية والصحة، offers.html للعروض. الأسعار والعروض توضيحية لأغراض التكليف الدراسي.
